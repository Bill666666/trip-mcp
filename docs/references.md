# 参考与来源

- [xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp)：本地浏览器、登录态持久化、MCP 业务工具及图文发布流程的架构参考。没有复制其代码。
- [ansike/ctrip-publish-skill](https://github.com/ansike/ctrip-publish-skill)：携程国内发布入口和部分控件定位线索。其部分 MCP 方法返回操作说明；本项目独立实现浏览器执行。
- [官方 MCP TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk)：协议、工具注册与 stdio 传输。
- [Playwright 认证文档](https://playwright.dev/docs/auth)：本地浏览器资料与登录隔离。
- [Trip Moments 网页发布](https://hk.trip.com/travel-guide/travelphoto-publish?locale=zh-HK)：2026-09-29 实际查看编辑器和地点候选。
- [携程内容中心](https://we.ctrip.com/publish/publishPictureText)：2026-09-29 访问后转入登录。

第三方项目及平台均不构成本项目的官方背书。依赖版本锁定在 package-lock.json。
