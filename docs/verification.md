# 验证记录

日期：2026-09-29 至 2026-09-30。版本：0.1.0 开发预览。

## 实站验证范围

### 携程国内站

- 在 MCP 独立浏览器中由用户完成登录。通过真实 stdio MCP 调用 `check_login`，返回 `logged_in=true`；重启进程后登录资料可复用。
- `list_notes` 已读到当前页 6 篇作品，分页信息为共 19 篇、4 页。验证覆盖标题、发布状态、日期及当前页范围。账号名称和作品内容不存入本仓库。
- 初始页面中的 `全部作品(0)` 是加载占位，不能作为空列表证据。适配器等待登录后的导航和实际内容卡片。
- 真实卡片为 `.c-m-c-container`，标题、状态和日期分别来自 `.title`、`.publish-status .status`、`.publish-status .date`。部分卡片不提供 href，因此不编造文章链接。
- 标题使用 `[contenteditable=true][role=textbox]`，正文使用 `[contenteditable=true][role=combobox]`；填写及移开焦点后的内容比对已通过。
- 页面建议标题 5–30 字，正文显示上限 3000 字。首版采用最多 30 字标题、正文加话题最多 3000 字的保守限制。
- 地点控件需要先展开 `.ant-select-multiple`，输入框才可编辑。候选是 `.search-input-detail .item-c`，并非标准 Ant Design option。
- 通过真实 MCP `search_destinations` 查询“上海”，返回 10 个候选，含城市、景点、车站和机场。此调用没有上传素材或提交笔记。
- 在真实编辑页选择“上海·中国”后，已核对地点标签及标题、正文保持一致；关闭测试页，没有保存平台草稿。

### Trip.com

- 香港站繁体中文编辑器曾在已有登录的浏览器核对真实 DOM：标题、`#textarea`、图片 input、地点候选、图片计数、条款选项及提交按钮。
- 本项目独立浏览器访问发布页时，实站返回 `whaleguard block`。这不是登录成功或账号密码错误的证据；本次 Trip 登录验收未完成。
- 已新增 `SITE_BLOCKED` 错误，并通过真实 MCP `check_login` 验证该返回值。没有添加验证码、站点拦截绕过或自动重试机制。

## 自动检查

- TypeScript 严格类型构建。
- 9 项自动测试：URL/图片/账号边界、账号锁、真实 MCP stdio 握手、两站浏览器模拟操作、并发和重启防重、结果未知处理、异步登录、站点拦截、国内零计数占位及实际卡片提取。
- 模拟测试使用本地拦截页面，覆盖国内富文本框、先展开再输入的地点选择器、自定义候选、额外内容声明控件等已观察结构。
- 提交前的内容校验和任务落盘，以及提交后连接中断不重发均有测试。

以 GitHub Actions 的实际结果作为每次提交的自动检查证据。
